🔥 Votes
How scoring works: Each vote is a score from 1–10. Votes are weighted — each vote is multiplied by the voter's weight before averaging. Regular users have weight 1×. Admins default to 10× (set via admin_vote_weight config). Individual weights can be overridden per user on the Accounts tab.
Weighted average = sum(score × weight) ÷ sum(weights). A single admin vote of 8 outweighs ten regular votes of 3. The 🌋/🔥/♨️ emoji on entries reflects this weighted average.
👤 IP Profiles
Each row is a unique visitor IP. Blocked users cannot submit entries, edits, comments, or victim statements.
Button guide:   Block — prevents user from submitting entries, edits, comments, or statements.   Grant/Revoke Admin — controls whether this IP can log into the admin panel without a password.   📋 Log — filters the activity log below to show only this IP.   🗑 Delete Data — permanently removes all comments, votes, and victim/sleeper statements from this IP.   Vote Weight — enter a multiplier (e.g. 2.5) and click Apply to change how much that user's votes count. Applies retroactively to all their existing votes. Default is 1x for regular users, and the admin_vote_weight config value for admins. Does not delete their submitted entries or edits. Use this to wipe a troll's interactions while keeping the content record.
